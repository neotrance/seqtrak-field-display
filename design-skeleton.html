Parameter labels · vary by selected preset

FILTER

Cutoff · resonance · output level

REVERB

Dry / wet · reverb time · LPF cutoff; GATED REVERB uses room size.

DELAY

Dry / wet · delay time · feedback. Cross delay exposes left-to-right and right-to-left times.

COMPRESSOR

Ratio · threshold · make-up gain

DISTORTION

Preset-dependent: dry / wet, overdrive, fold, input level, cutoff, presence, sample rate or bit depth.

MODULATION

Preset-dependent: LFO speed / depth, detune, spread, feedback, output and other documented controls.

DUCKER

Side-chain level · attack · release

OTHER

Preset-dependent controls include repeat length, gate time, play speed, freeze, drive and slice division.

SEND REVERB

Reverb time · room size · diffusion · plate type · high damp and LPF cutoff.

SEND DELAY

Delay time · feedback level · high damp; analog presets also expose delay input level.

Names follow the supplied SEQTRAK guide. Distortion presets 2–6 differ between MASTER and SINGLE. Parameter names and values must be shown only when received from a supported data source.
